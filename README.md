# Sways

Social Platform

A modern social platform designed for sharing blogs, discovering communities, and connecting with people who have similar interests.

# About the Project

This project is a social network built around content, communities, and shared interests.

Users can create and share blog posts, interact with other users, explore communities, and find people with similar interests.

The goal is to create a platform that is more than just a typical social feed — it is a place where users can share ideas, discover interests, and build communities.

# Features
👤 User profiles
📝 Blog and post sharing
💬 Social interactions
👥 Communities and clubs
🔎 Discover content and users
🎨 Personalized profiles
📚 Interest-based communities
📱 Responsive design
